# Тренажёр QA-инженера

Симулятор рабочего дня тестировщика: с 09:00 до 18:00, с задачами от QA-лида, Product Owner, техлида и разработчиков, стендапом, обедом, синками по проекту, прерываниями и отчётом руководителю. Работает целиком в браузере, без сервера.

## Что внутри

- **Поиск багов на стендах.** Пять тестовых стендов с внедрёнными дефектами: регистрация, корзина с промокодами, каталог с поиском и фильтрами, перевод с карты на карту, бронирование отеля. У каждого стенда есть требования и своя панель DevTools (Network и Console): часть багов видна только там. Найденное оформляется баг-репортами и сверяется с известными дефектами.
- **API-тестирование.** API-клиент вроде Postman и три тестовых сервера с багами: CRUD пользователей, заказы (включая IDOR и двойную оплату), авторизация и токены.
- **Рабочий день.** План на день, тикеты QA-xxx с ревью, возврат на доработку, рабочий чат, письменные стендап и отчёт QA-лиду. По понедельникам планирование спринта, по пятницам ретро.
- **Практика.** SQL на реальной базе стенда (sql.js) с «грязными» данными, которые нужно находить: дубли, «висячие» записи, двойные списания, расхождения сумм, а также результаты автотестов (flaky-тесты, процент прохождения). Кейсы по тест-анализу, тест-дизайну (классы и границы, таблицы решений, переходы состояний, pairwise), тестовой документации, баг-репортам, DevTools, логам и прод-инцидентам, мобильному тестированию, автоматизации, нагрузке и безопасности, регрессу и решению о релизе. Тесты по теории, рабочие ситуации.
- **Уточнение требований.** Созвон с аналитиком, техлидом или PO перед тестированием: собеседника играет ИИ, скрытые правила и граничные случаи раскрываются только на правильные вопросы.
- **Сквозной проект.** «ТехноМаркет: новый чекаут», 10 этапов от анализа требований до решения о релизе.
- **Курс «QA-инженер с нуля».** 11 модулей и 29 уроков с мини-проверками и ссылками на практику.
- **ИИ-наставник (бесплатно через Google Gemini или платно через Claude).** Ревью решений и баг-репортов, подсказки и разбор, пробное собеседование, разбор вакансии, генератор новых заданий, недельный коуч.
- **Продуктивность.** Адаптивный план под слабые места, цикл ошибок с интервальным повторением, помодоро и режим фокуса, шаблоны артефактов (баг-репорт, тест-кейс, чек-лист, тест-план, отчёт о тестировании, чартер исследовательской сессии, чек-листы API и мобильного приложения, постмортем).
- **Измерение роста.** Ежемесячный ассессмент, графики результата и скорости, матрица компетенций Junior / Middle / Senior.
- **Отчётность и карьера.** Отчёты за день, неделю и месяц в Markdown или PDF. Портфолио для GitHub с баг-репортами и работами по проекту.

## Запуск

Откройте `index.html` в браузере или опубликуйте через GitHub Pages (Settings → Pages → ветка `main`).

Прогресс хранится в `localStorage` браузера. Для переноса на другое устройство используйте экспорт и импорт резервной копии.

## ИИ и приватность

По умолчанию используется бесплатный тариф **Google Gemini**. Ключ можно получить на aistudio.google.com. Если у модели кончается бесплатная квота, тренажёр сам переключается на другую. Как платная альтернатива доступен Anthropic Claude.

Ключ вводится во вкладке «Настройки» и хранится только в вашем браузере. Запросы уходят напрямую в API провайдера. На бесплатном тарифе Gemini не вставляйте в ответы персональные и коммерческие данные.
